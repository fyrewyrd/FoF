                                      Information
1) You need to set the value for how much you can enchant an item - you can do it with a script Upgrade.cs (public static int MaxUpgrade = 7;)

2) Values: a) holes - the number of holes in the item for enchanting his rune
		   b) upgrdaeIND - with which rune the item was enchanted

3) Settings in script Upgrade.cs
    1) bool NeedHoles - Are holes for enchantment necessary?
	2) bool DifferentRunes - Can the item be enchanted with different runes? (for example, shield - defense and attack)
	3) bool ConsiderItemLevel - Does item level affect enchantment chance  (for example, the higher the level the harder to enchant)
	4) float DifficultyOfEnchantment - value of the base complexity of enchantment
	5) info time - time which displays a message in the enchantment panel
	6) bool UseTheChanceOfRarityItem - depending on the rarity of the item, it may have its own value which is used when enchanting (DefaultBaseChance)
	7) float DefaultBaseChance - value of DefaultBaseChance if bool UseTheChanceOfRarityItem = false

	8) bool ItemDestruction - can the item be destroyed if unsuccessful enchantment
	9) bool RunesDestruction - can all the runes inserted in the item be destroyed if the enchantment is unsuccessful

   10)  bool show Successfully Enchantment On Chat -
   11)  int show Successfully Enchantment Amount -
   12)  bool show Failed Enchantment On Chat -
   13)  int show Failed Enchantment Amount -
